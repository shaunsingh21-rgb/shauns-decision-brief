# AVL Tech Hub: quick start for trainers (one page)

Rules the app enforces (they are not optional): sign-off needs a **quiz score of 80% or more** and **every practical skill scored 2 or more**; the module must be **Approved**; you can **never score or sign off yourself**; editing an approved module sends it back to **Needs review**. Walked through in a browser with a trainer, a technician and a leader account.

## 1. Create a module
1. **Training**, then **New module**. Give it a title, choose a level (1 to 5), add a short summary, optionally link the equipment it is about. (The New module form was driven through the app's data call in my test, not through the on-screen form; check the first screen when you use it.)
2. The new module is a **Draft**. A banner says it is not approved yet.

## 2. Add the quiz
Open the module. Under **Written quiz** choose **Add a question**: type the **Question**, put **one answer per line** in **Answers** (2 to 6), type the **number of the correct answer** (1 is the first line). Choose **Add question**. Repeat. Trainees never see the correct answers; the server marks the quiz.
Limits to tell trainees: every question must be answered; 6 attempts per module per hour.

## 3. Add practical skills
Under **Practical skills** choose **Add a practical skill** and type the skill ("Set a gain level"). Add every skill the trainee must show. A skill that already has scores cannot be removed.

## 4. Videos (optional)
**Lesson videos** then **Add a lesson video**. SharePoint is recommended: in SharePoint choose Share, then Embed, and paste the embed link. Question checkpoints stop only **uploaded** videos by themselves; on SharePoint and link videos the trainee answers each question when the video reaches its time.

## 5. Send for review
**Submit for review**. The status becomes **Needs review**. Only a team leader (or a custom role that includes "Approve training material") can **Approve**. Until then nobody can be signed off on it. If you edit it later it returns to Needs review.

## 6. Score a trainee
When the module is **Approved** and the trainee has done the work: open the module, open **Trainer: score and sign off**, choose the **Trainee** (the list includes everyone whose role can take training, including leaders and other trainers). The page shows their written result ("Written: 100% ✓") and each skill. Pick 0, 1, 2 or 3 and choose **Save score**:
0 Not demonstrated, 1 Needs coaching, 2 Competent with minimal help, 3 Independent.
Scores work offline and are ordered by when you gave them.

## 7. Sign off
Choose **Sign off this trainee** (add a note if useful). If something is missing, the app lists exactly what ("Written: best quiz score is 60%, needs 80%", skills not yet 2). A sign-off is kept as history. If the module changes later it shows **out of date**; choose **Renew the sign-off** once the trainee meets the current rules. The **Skill matrix** shows the latest score per skill and a tick for signed off.

## Cannot do
Approve (by default), sign yourself off, change a sign-off after the fact, or grade a quiz offline (answers are marked on reconnect).

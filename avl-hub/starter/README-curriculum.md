# Starter curriculum (SAMPLE)

File: starter-curriculum.json. Format avl-hub-content v1. 18 modules, 90 quiz questions, 78 practical skills, 5 levels.
Levels: 1 Foundations (observe), 2 Assist, 3 Operate supervised, 4 Operate independently, 5 Lead and teach.

## Import
1. Sign in as an administrator (needs "data.manage" and "training.author").
2. Administration > Import content. Choose the file. Run the preview (dry run) first, then import.
3. Every module arrives as Draft with the summary starting "SAMPLE – review before use." Re-importing is safe (existing modules are skipped).

## Review before anything is approved
- A trainer reads each module, edits it to match how YOUR team works, and fixes or deletes anything that does not.
- Add equipment links, videos and team-specific steps; the sample is deliberately generic and contains no models, specs or links.
- Check every question has one clearly right answer for your team. Known weakness: the right answer is often the longest option; rewrite some so length is not a clue.
- Remove "SAMPLE – review before use." from the summary only once reviewed, then submit for review and approve (sign-off is blocked until approved).
- Skills are phrased as observable behaviours; a trainee cannot be signed off unless every skill scores 2+.
